## 守ること（全員）
- データは架空のみ。ですます調。難しい言葉を使わない。画面の文字は最小限（今の画面の作法に合わせる）
- 認証（src/auth.js、wrangler.jsonc の run_worker_first）を触らない。API キーをファイルに書かない
- **自分の担当ファイル以外は編集しない**（index.html / app.js / style.css の配線は宮川側の Claude がまとめて行う）。必要な配線は、担当モジュールの先頭コメントに「index.html に足す要素」「app.js から呼ぶ関数」を書いておく
- `npm test` が通る状態で終える（自分のテストを test/ に足す）。`npm run dev` でポートがぶつかるので、ブラウザ確認は `npx wrangler dev --port <自分の番号>`
- 公開（deploy）しない

## 共通の形
- 保存は `public/store.js`（localStorage）: `load(key, fallback)` / `save(key, value)` / `appendLog(key, {what, before, after, ...})` / `clearAll()`
- 画面データは `/api/data`（GET、POST で `{ base, folder, csv, overrides }`）。計算は全部サーバー `src/data.js build()`
- 読み取り結果（内示 1 版）の形 = `src/data.js` の `FOLDERS[].versions.sep` と同じ: `{ date, qty, due, options: [], note }` ＋ `reading: [{ field, value, from, check, ask? }]`
- 案件の形: `{ id, customer, name, model }`。新しい案件は `id: 'u' + 連番`
