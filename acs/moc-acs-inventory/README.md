## 画面の構成（10/5 夜 改修版）

ACS 様の現場（IT に詳しくない購買担当）が迷わないよう、「分析画面」ではなく「**今日やることリスト**」の形。画面の文字は最小限、式や用語は押したときだけ。

- 左上 **「内示をここに置く」**：押す／ファイルを落とすと「読み取り中 → 案件名 → 変わった点」と進み、「組立セル AS-500 導入」の変わった点が開く（デモ用。中身は読まない）
- 左 **案件**（6 件）：すべて／大和精密製作所の 3 案件／今回の内示が未着の 3 件（「未着」。マウスで理由）
- タブ 3 つ
  - **やること**（最初に開く）：1 件 1 行「相手 ＋ 何をする」＋ 一言。赤＝遅れ、黄＝余る、青＝確認。右に「なぜ？」「文面」
  - **内示の変わった点**：今回の内示の札（台数・希望日・仕様・確かめること。変わった札に色）→ 変更カード（増えた／前倒し／仕様変更／取消）→ 影響する部品 6 列 → 余る部品（回せる先つき）
  - **部品の一覧**：全部。行を押すと「なぜ？」
- **なぜ？**：式に数字が入った短い文を 1 行ずつ（例：`9/25 ＋ 納期 21日 ＋ 遅れ連絡 7日 ＝ 10/23 に届く`）。専門用語なし
- **文面**：メーカー／お客様／社内向けの下書き。コピー、AI に言い回しを変えてもらう
- 下 **「？ 計算のしかた」**：7 行の式（現場の言葉）
- 右下 **「AI に聞く」**：押したときだけ開く。質問例は短く、選択中の案件の型番だけ。AI には選択中の案件の表だけ渡す
- 基準日は 9/25 固定（画面右上「9/25 時点」）。URL に `#base=2026-10-06` を付けると今日の日付で見られる（商談では使わない想定）
