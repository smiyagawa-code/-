公開後の確認（必ず）: ログインして開き、左で「組立セル AS-500 導入」を選び、AI に「この案件で遅れの恐れがある部品は？」と聞く。
答えに出る型番が **D-1178・AS-06-148・SV-2030 だけ**（その案件の「納期の遅れ」タブと同じ）なら合格。ほかの型番が出たら公開版を見せない。

## 画面の構成（作り直し版）

- フォルダ 6 件（内示が届いているのは株式会社大和精密製作所の 3 案件：第2工場 外観検査ライン増設／組立セル AS-500 導入／クリーン仕様 搬送ユニット。残り 3 件は「9月版 未受領」で理由つき）
- タブ 6 つ：内示の変更点（最初に開く）／手配を急ぐ部品／納期の遅れ／フォルダ／計算の決まり／AI の読み取り
- 「根拠」ツールチップに式と数字（必要数 → 不足 → 追加手配 → 入手見込み → 遅れ → 発注期限）。「計算の決まり v1」タブに式の一覧
- 内示の変更点カード（増量／前倒し／オプション／取消）→ 影響部品（不足列あり）→ 過剰になる部品（取消・仕様変更で不要になる発注残。他案件への振替候補つき）→ 次のアクションの文面下書き（コピーできる）
- 右「AI に聞く」チャット（読み取り・注意書き・文面下書き・表への質問に限定。数字は作らない）。選択中フォルダの表だけを AI に渡し、おすすめ質問もフォルダ連動
- 基準日は 9/25（想定）が既定。右上で 10/6（商談日）に切り替えられ、切り替えると説明文も変わる
