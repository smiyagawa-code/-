## 画面の構成

- **左: 見積依頼の受信箱** 5 件（内訳明細書 PDF／メール本文／FAX 手書き／Excel／図面のみ）。要確認の件数と回答期限が見える
- **読み取り結果** 件名の出どころ（図枠・メール件名）、人が判断する行（芯数なし・「〃」・かすれ・件名）に「確認済みにする」、自動で処理した点（合算・在庫不足の補填・単価表の版・重量物）、拾えなかった品目の追加
- **単価と根拠** 行ごとに 在庫／直送・価格ランク・掛率・単価・備考 を手直しできる。「根拠」で 建値 × 掛率 ＝ → 端数処理 → 金額 の式。拠点（福岡支店／大阪本社）を右上で切り替えると掛率が変わる
- **見積書** Excel 様式のプレビュー（ロゴ枠・宛先・件名・明細・小計・税・合計・条件）。1 行ごとの注記、任意の位置に空白行（自由記入）・重量（概算）・送料の条件、数量の内訳（100m×3本）、承認フロー（承認依頼 → 承認 → 送付・リンク共有）、回答メールの下書き（コピー）
- **単価表の管理** メーカー 20 社（毎月更新 10 社）の取込状況、今月の差分（CV 系 +3%）、OCR 取込の流れ
- **計算の決まり v1** 8 項目と掛率の表
- **右: AI に聞く** 読み取りの説明・要確認の整理・根拠の読み上げ・文面の下書きだけ。単価は計算しない。選択中の依頼と手直しの内容だけを渡し、おすすめ質問も依頼連動
